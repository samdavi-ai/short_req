🖥️ Hardware Requirements (Physical Server)
NVIDIA GPU(s): Dedicated graphics cards (e.g., RTX 3090, 4090, A100, or T4) capable of running TensorRT/ONNX. This is strictly required for the AI video processing.
CPU: A high-core-count processor (e.g., AMD EPYC or Intel Xeon) to handle video stream decoding and network routing.
RAM: Minimum of 32GB to 64GB of system memory.
Primary Storage (NVMe/SSD): Fast storage for the operating system and PostgreSQL database operations.
Secondary Storage (HDD/SSD): High-capacity storage for saving video snapshots, face crops, and archived alerts via MinIO.
Network Interface: High-bandwidth gigabit (or 10-gigabit) network card to ingest multiple live RTSP camera feeds without bottlenecking.
🐧 Host OS & Core Software Requirements
Operating System: A Linux distribution (Ubuntu 22.04 LTS is highly recommended).
NVIDIA GPU Drivers: The latest proprietary NVIDIA drivers installed on the host OS.
Docker Engine: The core container runtime to host the application.
Docker Compose: Needed to orchestrate the multi-container microservices.
NVIDIA Container Toolkit: A crucial add-on for Docker that allows the containers to access the physical GPUs.
🌐 Network & Access Requirements
Camera Access (RTSP): Network access to the live IP cameras, including the exact RTSP stream URLs, usernames, and passwords.
Firewall / Whitelisting: Internal network rules allowing the host server to talk to the IP cameras and allowing users to access the React dashboard port (usually port 80/443).
Floor Plans: High-resolution image files (PNG/JPG) of the airport terminals/floors to upload into the dashboard's Layout Editor.
📦 Application Stack (Spun up automatically via Docker)
When you run the deployment, Docker will automatically download and start these specific technologies: 15. Frontend Application: React + TypeScript (served by Nginx). 16. Backend API: Python FastAPI (handles REST and WebSockets). 17. AI Inference Workers: Python workers running YOLOv8, ByteTrack, ArcFace, and TransReID models. 18. Task Queue System: Celery (workers) + Redis (message broker). 19. Relational Database: PostgreSQL (stores users, layouts, and alerts). 20. Vector Database: Milvus or FAISS (stores and searches AI embeddings for Person Re-Identification). 21. In-Memory Cache: Redis (handles WebSocket pub/sub and live state). 22. Object Storage: MinIO (acts like an internal Amazon S3 to store images and floor plans). 23. Monitoring Stack: Prometheus and Grafana (for tracking system health and AI latency).
⚙️ Pre-Deployment Configurations
Environment Variables (.env file): Setting up secure passwords for PostgreSQL, Redis, MinIO, and JWT authentication secrets before starting the containers.
Deployment Command: Running docker-compose -f docker-compose.yml -f docker-compose.gpu.yml up --build -d to launch the entire stack.
